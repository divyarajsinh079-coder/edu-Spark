# EduSpark – A Digital Learning Space

A responsive, static Class 10 learning website inspired by the supplied design reference.

## Project structure
- `index.html` – Homepage
- `lessons.html` – 10 lesson overview cards
- `examples.html` – Practical learning examples
- `practice.html` – Interactive MCQ quiz
- `teachers.html` – Teacher resources
- `about.html` – Project information
- `feedback.html` – Front-end feedback demo
- `assets/css/style.css` – Shared styling
- `assets/js/script.js` – Shared JavaScript
- `assets/images/` – Add your images here

## Run locally
Open `index.html` in a modern browser. For a local development server, use VS Code Live Server.

## Publish with GitHub Pages
1. Create a public GitHub repository named `eduspark`.
2. Upload all files and folders in this project. Keep `index.html` in the repository root.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for deployment. Your site URL will look like `https://YOUR-USERNAME.github.io/eduspark/`.

## Embed in Google Sites
Publish the GitHub Pages site first. In Google Sites choose **Insert → Embed → By URL**, paste the published URL, resize the embed, and publish the Google Site.

## Important notes
- Google Sites does not execute PHP. This is a static HTML/CSS/JavaScript project.
- The quiz runs in the browser; it does not save scores to a database.
- The feedback form is a front-end demonstration and does not send submissions. Connect a form service if you need to receive feedback.
- Replace sample chapter titles/descriptions with the correct textbook content for your course.
- Add your own project details (student name, college, guide, academic year) before submission.
